# UI Design Review

Review:
- visual hierarchy
- spacing and rhythm
- typography
- responsive behavior
- loading/empty/error states
- accessibility
- component reuse
- shadcn correctness
- Tailwind token consistency
- line accent correctness (loans green / real-estate amber; never mixed on one screen)

Use Playwright MCP if the app can run.

Return:
- Blocking issues
- Improvements
- Quick wins
- Suggested patches
- Production readiness verdict
