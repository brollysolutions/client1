# Reviewed provider logos

Reviewed on 2026-09-14 for the ten canonical bank names already seeded by the application. No providers, offers or partnership claims are created by this change. Assets retain their original artwork and bytes. Trademarks belong to their respective owners.

Nine assets are from official bank sites. YES BANK uses the author-attributed Wikimedia copy of the 30 May 2023 identity after the official image endpoint failed to load; the identity was cross-checked against the bank's [brand announcement](https://www.yesbank.in/content/published/api/v1.1/assets/CONTB8477AE871C34111AFC87F9819204B5F/native/launch_of_refreshed_yb_brand.pdf) and [file provenance](https://commons.wikimedia.org/wiki/File:Yes_Bank_Logo-01.png).

The read-time fallback requires an exact case-insensitive canonical name and provider type `bank`. Verified managed uploads take priority. Unverified uploads remain hidden; unknown identities retain the existing named fallback and Admin upload workflow. The registry does not change provider timestamps or write to the database.

SVG review rejected scripts, external references, event attributes, embedded images and foreign objects. Raster file signatures were checked. Canara's server labels a WEBP as PNG; the local extension follows its actual file format. Original white wordmarks use a dark plate. YES BANK's original canvas is framed with CSS without changing its pixels.
