# Runbooks

Operational procedures for production. Add one per recurring incident/operation. Each runbook:
trigger, preconditions, steps, verification, rollback, and escalation.

Seeds:
- `migration.md` — safe expand/contract migration deploy.
- `scheduler-jobs.md` — scheduler ownership, manual rerun, duplicate-run handling.

Planned: cache-incident, backup-restore, rollback, payout-reconciliation.
