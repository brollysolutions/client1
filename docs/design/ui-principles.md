# UI Principles

We build clean production SaaS interfaces.

Principles:
- Make the user goal obvious within 3 seconds.
- One primary action per screen.
- Prefer calm, readable layouts over flashy decoration.
- Use generous whitespace, but avoid low-density dashboards.
- Use consistent card, table, form, and page patterns.
- Every async surface needs loading, empty, error, and success states.
- Every form needs labels, helper text, validation, and submission feedback.
- Every page must work on mobile, tablet, and desktop.
- Use shadcn/ui primitives and Tailwind design tokens.
- Avoid random colors, one-off shadows, and inconsistent border radii.
- Respect the locked line palette (loans green / real-estate amber, never mixed on one screen).
