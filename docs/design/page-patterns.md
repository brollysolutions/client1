# Page Patterns

## CRUD List Page

Required:
- page title and description
- primary create action
- search/filter controls
- table or card list
- pagination or infinite scroll decision
- loading skeleton
- empty state with action
- error state with retry

## Detail Page

Required:
- title area
- key metadata
- primary action
- secondary actions menu
- related data sections
- audit/history if relevant

## Dashboard

Required:
- time range control
- metric cards
- trend chart
- actionable table/list
- empty states for no data
- clear explanation of metric definitions

## Status timeline (this product)

Loan and property journeys render the internal pipeline as a read-only timeline for clients
(verbatim status; `on_hold`/`rejected` show `status_reason`). Agents see collapsed milestones.
