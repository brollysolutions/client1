# Design Review Checklist

- [ ] Clear primary user goal; one dominant primary action
- [ ] Consistent spacing scale and border radii
- [ ] Strong typography hierarchy
- [ ] Loading, empty, error, and success states present
- [ ] Mobile, tablet, desktop layouts verified
- [ ] Keyboard accessible; visible focus
- [ ] Colour contrast meets AA; accent not the only signal
- [ ] Only design tokens used (no random colors / one-off shadows)
- [ ] Correct line accent (loans green / real-estate amber); not mixed on one screen
- [ ] shadcn/ui primitives used where appropriate; no needless bespoke components
- [ ] Inspected with Playwright MCP
- [ ] typecheck + lint pass
